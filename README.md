# CRL Hitbox

> A Cleanroom-only runtime hitbox and collision-query library for Minecraft 1.12.2.
>
> 面向 Minecraft 1.12.2 Cleanroom-only 环境的运行时碰撞箱与碰撞查询库。

This repository currently contains only a minimal, buildable Minecraft 1.12.2 / Cleanroom Loader 0.6.8-alpha / Java 25 project skeleton. Runtime hitbox, collision-query, networking, rendering, combat, and certified-geometry features have not been implemented; Phase 1A feature work has not yet begun.

The finalized project identity is Maven group and Java base package `dev.crlhitbox`, main class `dev.crlhitbox.CrlHitbox`, and initial development version `0.1.0-SNAPSHOT`. Authors, project URLs, issue tracker, and distribution license remain unresolved.
